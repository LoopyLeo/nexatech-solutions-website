A few helpful details.

What should I include in a website brief?

Describe the purpose of the site, target audience, required pages, key functionality, content readiness, references, and preferred launch date.

Can a GitHub Pages site run WordPress or PHP?

No. GitHub Pages serves static files such as HTML, CSS, JavaScript, and images. A live WordPress installation requires a PHP-capable host and a database.

How can this demo receive submissions?

Connect the form to a hosted form service such as Formspree, or deploy a backend endpoint. The included mailto approach simply prepares an email in the visitor's email application.
