# How this portfolio maps to the WordPress Web Developer Intern role

| Role requirement | Where the portfolio demonstrates it |
|---|---|
| WordPress website design and development | `wordpress.html`, `services.html`, homepage services and demo project briefs |
| Elementor and Gutenberg | `wordpress.html#elementor` |
| Theme customization and child themes | `wordpress.html#themes`, with a small CSS override example |
| Responsive web design | Shared responsive breakpoints in `assets/css/styles.css` and mobile navigation in `assets/js/main.js` |
| Website speed and optimization | `wordpress.html#performance` and the optimization demo project |
| SEO best practices | Page-specific titles/descriptions, semantic structure, `robots.txt`, and `sitemap.xml` |
| Troubleshooting and maintenance | Services page and WordPress site QA concept in Projects |
| Basic HTML, CSS, JavaScript | Static source files and responsive interactions |
| Plugin awareness | WordPress page explains plugin selection, compatibility, and update checks |

## Interview guidance

Be clear that this is a portfolio/demo site. Explain the design decisions, responsive layout, reusable styles, accessibility details, SEO metadata, and the WordPress workflow you practiced in LocalWP. Do not describe concept cards as paid client projects or claim WordPress/PHP/plugin functionality that you have not built and tested.
